# Reviews

Keep review light and aimed at catching real faults. David's reaction to a matched render decides faithfulness; these checklists catch the faults that cost reprints.

## Faithfulness

Show the concept and the current model, rendered from the same view, side by side in one image. Use neutral materials for at least one view, because dramatic lighting hides form errors. Note any visible departure from the concept and why, using the compromise register in [concept and faithfulness](../../../shared/concept-and-faithfulness/concept-and-faithfulness.md) (`shared/concept-and-faithfulness/concept-and-faithfulness.md`) only when the departure is a real trade-off David should decide.

## Before a long print

- Proportions match the real envelope; nothing is stretched to fit.
- Protected zones are clear: seam, pull notches, service openings, magnet pockets, connector ports.
- Frames and bands wrap every corner; edge rounds survive along every side.
- Protruding ornament is chunky or a separate part; nothing thin stands free.
- Mating features (pegs, tabs, sockets) are exact and unsmoothed.
- Stack-ups across separable parts add up (see engineering and validation).
- Print orientation, supports and bed size are decided; carved faces are not on the bed.
- A coupon covers the riskiest new interface, unless David waived it.
- Moving parts clear through the whole motion, not only at its ends; print-in-place mechanisms were tested on their own first.

## Before handing over a print folder

- Every part needed to build the object is in one numbered folder, with orientation and quantity in each file name.
- Exported files are closed solids at the right scale and orientation.
- An assembled render of the exported files shows magnet pockets, seams and pull bays facing their mating parts.
- PRINT-AND-TEST.md lists print order, settings, hardware, assembly and what is still untested.

## Before changing a part

- When David names a part by colour or look in a preview, confirm which file it is before changing it ("the gray dice holder" was the lift key dock).
- Change only the part asked for, and undo anything changed by mistake.
- Never change a locked release; start a successor version.

## Independent reviewer

Use a separate reviewing agent only for a new box architecture, a safety-relevant change (power, heat, batteries), or when David asks. How to brief it and use its verdict is in [independent review](../../../shared/independent-review/independent-review.md) (`shared/independent-review/independent-review.md`).
